ONETV

Uma experiência de mídia para sua TV

O ONETV é um projeto de aplicativo de mídia para dispositivos Android TV e Roku.

Sobre o projeto

O projeto busca organizar e apresentar informações de filmes e séries de forma simples, incluindo títulos, sinopses, gêneros e imagens de capa quando disponíveis.

Metadados e imagens

Está planejada a integração com a API do The Movie Database (TMDB) para consultar informações e imagens de filmes e programas de televisão.

O ONETV é um projeto independente e não é afiliado, endossado ou certificado pelo TMDB.
